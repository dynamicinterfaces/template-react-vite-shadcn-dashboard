# Business Intelligence Dashboard

A full-featured business intelligence and operations dashboard built with React, Vite, and Shadcn UI.

## Features

- **Financials** — P&L overview, budget tracking, treasury management
- **Accounting** — Income statement, cash flow statement, AR aging reports
- **Analytics** — Business performance metrics and visualizations
- **Sales** — Pipeline and revenue tracking
- **People & HR** — Headcount, org chart, team management
- **Operations** — Process and workflow visibility
- **Intelligence** — AI-driven insights and reporting
- **Kanban** — Task and project management boards
- **Authentication** — Login, registration, Google OAuth

## Tech Stack

- **Build Tool:** [Vite](https://vitejs.dev/)
- **Routing:** [React Router](https://reactrouter.com/)
- **UI:** [Shadcn UI](https://ui.shadcn.com) + [Tailwind CSS](https://tailwindcss.com/) + [Radix UI](https://www.radix-ui.com/)
- **Language:** [TypeScript](https://www.typescriptlang.org/)
- **Forms:** [React Hook Form](https://react-hook-form.com/) + [Zod](https://zod.dev/)
- **Icons:** [Lucide](https://lucide.dev/)
- **Linting:** ESLint + Prettier

## Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) v22+
- npm

### Installation

```bash
git clone https://github.com/dynamicinterfaces/template-react-vite-shadcn-dashboard.git
cd template-react-vite-shadcn-dashboard
npm install
```

### Development

```bash
npm run dev
```

### Build

```bash
npm run build
```
